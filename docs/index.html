Three layers, one set of IDs

IIIF

Page images and manifests. Already in place at Gpura.

PAGE-XML

Where every region and line sits on the scan, printed or handwritten, in reading order. ALTO exported from it.

TEI P5

The edition: structure, metadata, reader annotations, damage, uncertainty, each line pointing back to its place on the image.

The harness

The repository holds the pipeline that produced the specimen. Each item is a folder of images and reviewed line data; one command rebuilds every encoding, validates it against the official PAGE, ALTO and TEI schemas, and regenerates the specimen page.

python3 run.py items/american-aikyanadu-1971

Given a Gpura link instead, it fetches the metadata, scans and Gpura’s own text, finds the printed lines, aligns the text to them, and builds the same outputs:

python3 run.py https://gpura.org/item/1957-sir-isaac-newton --pages 15-17

Source material: Gpura (gpura.org), Indic Digital Archive Foundation; the items used here are in the public domain. Transcriptions in the specimen are model-made and await human verification. This is an independent proposal, not a Gpura publication.
